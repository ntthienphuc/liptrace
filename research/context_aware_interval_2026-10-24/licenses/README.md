# Licensing and redistribution scope

This directory records the terms that were checked for the current release candidate.
It does not grant permission to redistribute a third-party corpus, checkpoint, or source
archive. The public GitHub subtree carries the current license files; the final author-approved
copyright holder and author metadata must replace the placeholder before submission.

## Study code and derived numerical data

The current author choice is MIT for original study code and CC BY 4.0 for the derived
numerical tables. The copyright holder and final author list still need to replace the
placeholder in `LICENSE-MIT.txt` before publication. The derived tables contain counts and
anonymized source aliases; they do not contain transcripts, raw recordings, or model weights.

## Third-party material

- VLR v2 is linked to its versioned Zenodo record. The checked DOI metadata reports
  Creative Commons Attribution 4.0 International. Follow the record's current terms and
  cite the dataset.
- LRS2 is distributed through the Oxford--BBC data-sharing process. The agreement and
  non-commercial academic conditions govern access; the original recordings and restricted
  metadata are not included here.
- MuAViC/mTEDx reports CC BY-NC 4.0 in the official repository. TED/TEDx source terms and
  attribution requirements also apply.
- ViCocktail is linked to the authors' repository and dataset page. The inspected dataset
  page did not expose a clear license field, so no ViCocktail recording is redistributed.
- Auto-AVSR, vsr-low, and any other preserved upstream source retain their own licenses.
  The Spanish upstream license is kept in `vsr_low_LICENSE`.

## Publication checklist

Before submission, replace the author placeholder and add final citation metadata while
preserving all third-party notices. Describe only the code and derived tables as public; do not describe
the entire package as open data while LRS2, local checkpoints, or ViCocktail media remain
access-controlled.
